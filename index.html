OpenAlex FWCI チェッカー

機関を指定して、OpenAlex が論文ごとに付けている FWCI（Field-Weighted Citation Impact）を集め、機関の「平均 FWCI」が何に支えられているか（分野・出版年・少数の高被引用論文・大規模共著）を確認するツールです。データはブラウザから OpenAlex API に直接問い合わせて取得します。サーバーへの登録やインストールは不要です。

FWCI とは？ 機関の FWCI をどう読むか（はじめに読む）

FWCI（Field-Weighted Citation Impact）

1本の論文について「実際の被引用数 ÷ 同じ出版年・同じ分野・同じ文献タイプの論文が世界平均で受ける被引用数（期待値）」を計算した値です。1.0 が世界平均、2.0 なら平均の2倍引用されていることになります。分野ごとの引用慣行の違い（医学は多く、数学や人文学は少ない、など）や、出版からの経過年数の違いをならして比べられるようにした指標です。

機関の FWCI は「論文 FWCI の算術平均」

Elsevier の SciVal などで示される機関の FWCI は、その機関が関わった論文の FWCI を単純に平均したものです。平均であることから、次の性質があります。

  • 分布が大きく偏っている。大半の論文は FWCI 1 未満で、ごく一部の論文が数十〜数百の値をとります。そのため中央値は平均よりかなり低く、1 を下回るのが普通です。中央値が 1 未満でも、それだけで「低い」とは言えません。
  • 論文数が少ない機関ほど、少数の論文で平均が大きく動く。1本の論文が平均に与える影響はおおよそ「その論文の FWCI ÷ 機関の論文数」です。例えば FWCI 500 の論文が1本あると、論文 1,000 本の機関では平均が約 0.5 上がりますが、10,000 本の機関では約 0.05 です。
  • 大規模共著論文はまるごと数えられる。数百〜数千名が著者に並ぶ国際共同研究（疾病負荷研究、大型ゲノム研究、診療ガイドラインなど）は極端に引用されやすい一方、各機関の貢献はごく一部です。それでも平均 FWCI では、著者が1名参加しているだけの機関にも論文1本分がそのまま加わります（フルカウント）。
  • 直近の論文は値が不安定。被引用は出版年を含む4年間で数えるため、出版から日が浅い論文の FWCI は暫定値で、今後大きく変わることがあります。

このため、機関の FWCI は平均だけでなく、中央値、被引用上位10%論文の割合、上位論文や大規模共著を除いた平均と並べて読むことをおすすめします。

OpenAlex の FWCI

  • OpenAlex は論文ごとに fwci を提供しています。OpenAlex のヘルプによれば、被引用は出版年とその後3年間（計4年間）で数え、期待値は同じ出版年・文献タイプ・サブフィールドの論文の平均です。サブフィールドは掲載誌ではなく論文自体の内容から判定した主トピックによります。
  • 全論文に付くわけではありません。主トピックが割り当てられていない論文や一部の文献タイプでは fwci が空（null）です。結果の「文献タイプ・FWCI の付与状況」で、どこが欠けているかを確認できます。このツールの平均は FWCI が付いている論文だけで計算します。
  • FWCI とは別に、外れ値に強い指標として citation_normalized_percentile（同条件の論文の中での被引用の順位。上位10%・上位1% の判定付き）も併記します。

SciVal など他のデータベースの値とは一致しない

計算の考え方は同じでも、次の点が違うため、同じ機関・同じ期間でも数値は一致しません。

  • 収録論文の範囲（Scopus・Web of Science・OpenAlex で異なる）
  • 分野の分類（例: Scopus は掲載誌単位の ASJC 分類、OpenAlex は論文単位のサブフィールド）。同じ論文でも基準となる分野が変わり、FWCI が大きく変わることがあります。
  • 機関の範囲（附属病院・研究所を含むか、所属表記の名寄せ）。各データベースの機関定義によります。
  • 集計した時点（被引用は日々増えます）

このツールで確かめられるのは、公表された値そのものではなく、「平均が少数の論文に押し上げられていないか」「どの分野・どの論文が効いているか」といった構造です。

機関の指定について

  • OpenAlex では、大学と附属病院・研究所が別の機関として登録されていることがよくあります。検索結果の「関連機関」から確認し、含める場合と含めない場合を比べてください。「下位機関も含める」にチェックすると、OpenAlex 上で子機関として登録されている機関もまとめて対象にします。
  • 複数の機関 ID を指定した場合、いずれかの機関の著者を含む論文を1回ずつ数えます（重複は除外）。
このツールの仕組みと制限
  • OpenAlex API の /works を、機関 ID と出版年で絞り込んで全件取得し、ブラウザ内で集計します。
  • API キーなしでも使えますが、同じ IP アドレスからの利用で1日の無料枠を共有し、取得できるのは1回 10,000 件までです。それを超える機関は、OpenAlex の無料 API キーを「API キー」欄に入れてください。キーはこのブラウザ内にだけ保存され、OpenAlex への問い合わせにのみ使われます。
  • OpenAlex の一覧取得では著者が先頭 100 名までしか返らないため、著者 100 名以上の論文は1件ずつ全著者を取り直して「指定機関の著者数」「筆頭・最終・責任著者か」を判定します。
  • 結果は取得した時点の OpenAlex のデータです。被引用数やデータの修正により、日によって数値が変わります。
  • 条件はページの URL に入るので、URL を共有すれば同じ条件で集計できます（下の「URL で指定できる条件」「使用例」参照）。

使用例

リンクを開くと、その条件で集計を始めます。

  • 公表された機関 FWCI の中身を確かめる: 聖路加国際大学、2021–2025年。AERA ムック『大学ランキング2027』で FWCI 2.23（SciVal、2026年1月時点）と紹介された機関です。
  • 附属病院を含めた場合と比べる: 聖路加国際大学＋聖路加国際病院。
  • 同じ条件で別の機関を見る: 滋賀医科大学（同ランキングの値 1.76）。
  • 文献タイプを絞る: article と review だけで集計。
